Edite os campos e, na pré-visualização, clique em uma caixa de texto para selecioná-la. Arraste para mover; use o pequeno quadrado azul para redimensionar.

Dimensão e moldura

Os nomes do menu correspondem a caminhos sugeridos. Coloque os PNGs na pasta molduras do repositório ou carregue-os pelo botão.

A ilustração é exibida inteira, sem cortes.

A cor automática é estimada pelos pixels das bordas da ilustração central. Desmarque a opção acima para escolher uma cor manual.

Arranjos e impressão

Arranjo padrão carregado. O salvamento local fica neste navegador.

Para usar o arranjo em outro navegador ou computador, exporte o JSON e depois importe-o no outro dispositivo. Para imprimir, escolha A4, escala de 100% e desative “ajustar à página”.

Ajustes da caixa selecionada

Nenhuma caixa selecionada

Também pode editar X, Y, largura, altura e fonte numericamente. As medidas são percentuais da carta, para manter as proporções ao mudar seu tamanho.

Dica: selecione a caixa de texto; arraste-a para mover. Arraste o quadrado azul no canto inferior direito para redimensionar. A moldura permanece fixa e não é selecionável.
